# Lucky Rogue

fully developed in unity with assets from collaborators for the jam. Includes EnemyAI card system, deck system, ante scaling.
I included 8 abilities that can be purchased from the shop and placed in an inventory where 2 can be equipped at a time, some are passive.
Energy system, with a max of 5 energy and different actions such as ending turn or using abilities cost energy. 

Play here: https://yag1307.itch.io/lucky-rogue
